# Support Guidelines

Welcome to the Tehuti CLI community! We want to ensure you get the help you need. 

## Where to get help

### 1. I have a question or need help configuring Tehuti CLI
If you are struggling to configure providers, use MCP tools, or set up Identity-Based Access Control, please utilize **GitHub Discussions**. This allows the community to build a shared knowledge base.

### 2. I found a bug!
If you have found a verifiable bug (e.g., terminal tearing, QUIC HTTP/3 connection failures, or unhandled exceptions), please open an issue using the **Bug Report** template. Ensure you have searched existing issues first.

### 3. I have a feature request!
We'd love to hear it. Please open an issue using the **Feature Request** template. Describe the use-case clearly and how it aligns with Tehuti's architecture.

### 4. I found a security vulnerability!
Please read our [Security Policy](SECURITY.md) and email **security@theosirislabs.com** directly. **Do not** open a public issue.
